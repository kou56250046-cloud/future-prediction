# 見方タブとスキル解説 — 要件

作成日: 2026-09-17 ／ 規模: M ／ 状態: 承認済み（2026-09-17。見立ては Claude が執筆し画面に明記、実装後に Pages へ反映）

## 背景

ダッシュボードは1列の縦長ページで、11 ブロックが並ぶだけになっている。
Brier・skill score・需給比・前年同月差・被覆率など、読み方を知らないと誤読する数字が多いのに、
説明は README と各図の脚注に散らばっていて、画面の中から全体像をつかめない。

スキル需要のブロックは「直近月の前年同月差」で上位を並べているだけで、次の問題がある。

- **月次の前年同月差は揺れが大きい。** 直近月（2026-09）は月の途中で n=264。
  月次では typescript が -6.9pt で「減っているもの」の1位に出るが、
  4四半期ずつ束ねると 21.0% → 24.5% でむしろ伸びている
- 数字の並びだけで、そのスキルが何か・なぜ伸び縮みしうるか・今後どう見るかの解説が無い
- `ai_generic` は「AI という語への言及」でスキルではないのに、スキルと同じ列に並ぶ

本人は、キャリア判断の材料として「今後どのスキルが必要になり、どれが要らなくなっていくか」
を技術面の解説つきで読みたい。

### このプロジェクトの思想との関係

既存の要件は「予測の自動生成」を非目標にしている。予測を立てるのは人間で、機械は採点する側にいる。
今回の「今後の見立て」はこれとぶつかりうるので、次のように扱う。

- **データから言えること**（過去の変化の分類）と、**執筆者の見立て**（今後どうなりそうか）を画面上で分ける
- 見立ては手で書いた静的な文章で、執筆者（LLM であること）・知識の時点・執筆日と「データではない・採点されていない」を必ず表示する
- 見立ては予測台帳に登録しない。見立てを予測として採点したい人のために、登録の手順だけ示す
- 見立てとデータの向きが食い違うスキルには印を付け、見立てを鵜呑みにさせない
- 手で書く文章には見立てだけを書く。「データがどう動いたか」はビルド時に数値から出し、手書きしない（次の sync で古くならないように）

正典仕様（`.claude/specs/future-prediction/requirements.md`）の非目標「予測の自動生成」と受入条件 A4
（script タグ 0 件）は、この仕様に合わせて書き直す（C1・C2）。

## 非目標

- **職種×スキル、AI 言及×スキルの共起といった新しい指標。** `metrics.js` と指標ファイルの変更が要り、
  今回の目的（読み方と解説）から外れる。解説で必要を感じたら別の仕様にする
- **語彙（`config/taxonomy.json`）の追加・修正。** 新しい技術が 0 のまま出る問題は注意書きで扱う
- **見立ての自動生成。** ビルド時に LLM で文章を作らない。外挿から「今後」を機械的に言い切らない。
  見立ては手書きの静的な文章だけ
- **見立てを予測台帳へ自動登録すること。** 登録の手順を見せるだけ
- **既存のダッシュボードブロックの作り直し。** 月次の前年同月差で並べる今のスキルブロックはそのまま残す。
  例外として、スキルブロックの説明に「月次は揺れる。4四半期で比べた分類はスキル解説タブ」の1文とリンクを足す。
  `ai_generic` を並びから外すことはしない
- **スキル解説タブのグラフ（スパークライン・推移の SVG）。** 表と文章だけにする。推移はダッシュボードで見る
- **`config/metrics.json` の caveat の修正**（四半期で「12期前」となっている件など）
- **テーマ（ライト/ダーク）の切り替え UI、印刷用のレイアウト、英語版**
- **スキルごとの給与、日本市場についての解説**
- **GitHub Pages への自動デプロイ。** 公開は手動の `npm run deploy`。今回は検証が済んだあとに1回だけ手動で反映する（2026-09-17 承認）

## 制約

- npm 依存ゼロ。`dist/index.html` は単一ファイルで外部リソースを読まない
- インライン JS はタブの切り替えだけに使う。グラフや本文を JS で組み立てない（JS 無効でも全文が読める）
- 色は `scripts/lib/html.js` の CSS 変数だけを使い、ライト/ダーク両方で読めること
- 指標には分母 n を持たせる。分類の根拠として件数を画面に出す
- 手書きの解説は執筆日を持ち、180 日を超えたら画面で警告する
- 見立ての本文は Claude が執筆する（知識は 2026 年 5 月まで）。本人が後から直せるよう JSON で持つ。
  執筆者が LLM であることを画面に出す
- GitHub Pages は誰でも見られる。`npm run deploy` すると見立ても公開される。本人は公開を了承済み（2026-09-17）
